# Krishnaprasad S — Creative Designer Portfolio

Built with React, TypeScript, Vite, and Tailwind CSS, adapted from the Himal Journeys template.

## Development

```bash
npm install
npm run dev
```

## Build & Typecheck

```bash
npm run typecheck
npm run build
```

## Customizing Assets

Project artwork and hero visuals live in `public/assets/`. Replace any `.svg` file (or update `PROJECTS` in `src/components/ui/himal-journeys-template.tsx`) to showcase real campaign photography and renders.
